# 多言語ドキュメント管理方針

本プロジェクトではグローバル向け OSS 展開を前提とし、ドキュメントのプライマリ（正本）言語を **英語** とする。

### 1. ディレクトリ・ファイル構成
- **ルート README**:
  - 英語（正本）: `README.md`
  - 日本語: `README.ja.md`
  - それぞれの冒頭（1行目）に言語切り替えリンク（`[English](README.md) | [日本語](README.ja.md)`）を明記すること。
- **詳細ガイド (`docs/`)**:
  - 英語（正本）: `docs/*.md`
  - 日本語: `docs/ja/*.md`

### 2. 言語同期運用
- 仕様変更、機能追加、または設定変更に伴いドキュメントを更新する際は、原則として英語と日本語の双方を同期して更新すること。
- ただし開発スピードを優先し、一方の言語（英語等）を先行して更新することも許容する。その場合でも追従漏れを防ぐため、CI では未同期時に PR 上へ Warning アノテーションを表示してリマインドする（CI 自体はブロックせず継続）。
- 先行更新したドキュメントは、後続の PR やレビューまでに LLM 等を活用して他方の言語へ速やかに追従・反映すること。
